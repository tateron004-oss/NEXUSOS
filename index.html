How To Run The Full App

This GitHub entry page is static. The full NexusOS platform uses the Node server for login, subscriptions, automation, API workflows, and generated client assets.

Run locally:

npm start

Then open:

http://127.0.0.1:4288

For hosting, deploy with the included Dockerfile or render.yaml.
